# Нұртас Оңдасынов — ақпараттық сайт

Қазақ мемлекет қайраткері әрі ғалым **Нұртас Дәндібайұлы Оңдасынов** (1904–1989) туралы
бір беттік (single-page) сайт. Таза HTML + CSS + JavaScript, ешқандай фреймворксіз —
GitHub Pages-та тегін орналастыруға дайын.

## 📁 Файлдар құрылымы

```
nurtas-site/
├── index.html        # Негізгі бет (барлық бөлімдер)
├── style.css         # Қою көк (navy) дизайн, адаптив
├── script.js         # Навигация, таймлайн сүзгісі, галерея, ЖИ чат-бот
└── assets/
    ├── author.jpg    # Автордың (Қарасай Фатима) фотосы
    └── ai-video.mp4  # ЖИ видеосы
```

## 🚀 GitHub Pages-та жариялау (қысқаша)

1. GitHub-та жаңа репозиторий ашыңыз (мыс. `nurtas-ondasynov`), **Public** етіп.
2. Осы қалтадағы барлық файлды репозиторийге жүктеңіз (`assets/` қалтасымен бірге).
3. **Settings → Pages → Branch: `main` / root → Save**.
4. 1–2 минуттан кейін сайт мына мекенжайда ашылады:
   `https://ПАЙДАЛАНУШЫ.github.io/nurtas-ondasynov/`

## ✏️ Өзгерту

- Мәтінді — `index.html` ішінен.
- Түстерді — `style.css` жоғарысындағы `:root` айнымалыларынан.
- Чат-бот жауаптарын — `script.js` ішіндегі `knowledge` массивінен.
- Галереяға нақты сурет қосу үшін суреттерді `assets/` қалтасына салып,
  `index.html`-дегі `.gallery-ph` блоктарын `<img>`-ке алмастырыңыз.
